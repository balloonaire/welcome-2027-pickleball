# WELCOME 2027 Pickleball Invitation — Music Edition

Interactive smartphone and desktop invitation with fireworks, folding doors, animated RSVP and **original synthesized instrumental background music**.

## Music
- The first tap to reveal the card starts an upbeat original instrumental loop (browser permitting).
- The **♫ Music On / Music Off** button lets guests control playback.
- Audio is generated inside the browser via Web Audio; no MP3, external asset, streaming, licensing or internet connection needed.
- Smartphone browsers generally block audio until the first interaction.
- Music is intentionally instrumental, not a commercial song.

## Event
Sunday, 27 December 2026, evening. Exact time and venue are placeholders.

## WhatsApp RSVP
Edit `const EVENT` in `index.html` and set `whatsappNumber` to your real WhatsApp recipient in international digits (e.g. 60123456789 is a sample only). RSVP asks only name and contact number. Guests must press Send in WhatsApp.

## GitHub Pages
Upload `index.html` to the repository root, then Settings → Pages → Deploy from branch → main → /(root). The site has no external dependencies.
